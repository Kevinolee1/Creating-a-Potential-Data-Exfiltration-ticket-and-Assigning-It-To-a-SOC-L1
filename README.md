# Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1
A security alert was generated indicating possible unauthorized transfer or exfiltration of sensitive organizational data.
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/5f56386631c35a6f5a2dd58cbc607faa5fd9bce1/Screenshot%202026-08-18%20191322.png)
Select “Open a New Ticket” to initiate the incident documentation and investigation process.
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/5b36c0e3f40980c6aae21def6b762779835569fd/Screenshot%202026-08-16%20031949.png)
Enter the affected user's name and email address. Under Help Topic, select Security Incident. In the Issue Summary field, enter Potential Data Exfiltration.  
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/fdd5b9feda34f479cd914243cf3b7f0619e46263/Screenshot%202026-08-16%20020656.png)
In the text box, enter the relevant security alert details and a concise issue summary. Review the information for accuracy, then click Create Ticket to submit the security incident for investigation.
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/d810002323d5582bc76c9950f38e8dd630473cf2/Screenshot%202026-08-18%20011200.png)
Log in to your administrator account
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/447a7458c0b26dc974e16189d204cd9943d5e4ba/Screenshot%202026-08-20%20105651.png)
Select the Potential Data Exfiltration ticket to begin the investigation.
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/34fa75ea319f76685acbe4efc48beee52298980d/Screenshot%202026-08-16%20021936.png)
Change the ticket priority to Emergency to reflect the potential severity and urgency of the suspected data exfiltration activity.
![Image alt](https://github.com/Kevinolee1/Creating-a-Potential-Data-Exfiltration-ticket-and-Assigning-It-To-a-SOC-L1/blob/194754606a58a5ccad1a96589a687ed1dc22e6ca/Screenshot%202026-08-16%20032521.png)
Assign the ticket to the designated SOC Level 1 analyst for initial investigation and triage.
